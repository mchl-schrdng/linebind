# Linebind 0.1.0

The implementation is documented in the [README](../README.md),
[contract reference](configuration.md), [trust model](trust-model.md), and
[runnable examples](examples.md). This path remains available for links from
the original project brief; those documents replace the preparation draft.

The release scope is a local CLI, a versioned repository contract, native file,
text, manifest and document checks, opt-in external command checks, and a
self-contained report. Rules come from a caller-selected Git base. Findings,
incomplete analysis and proposed policy changes remain separate evidence.

Language-specific semantics depend on the configured check or external tool.
There is no universal architecture parser, general model-based judge, hosted
service, or built-in policy approval mechanism in this version.

For actual validation, run the test suite and the example runner described in
[Contributing](../CONTRIBUTING.md) and [Examples](examples.md). A prepared package
or passing fixture is not a claim of publication, user adoption or complete
repository coverage.
