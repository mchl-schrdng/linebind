# Linebind mecha — original generation prompt

Built-in Imagegen, 20 October 2026. The approved Cloud image is reused without
visual edits; only its original WebP encoding is copied into this repository.

Use case: ads-marketing. Create a genuinely exceptional original manga-mecha
illustration for the hero of a developer tool named Linebind. ART ONLY, no website
UI, no words or letters. User art direction: very polished manga with an
Evangelion-inspired biomechanical mecha sensibility, expressive austere composition
and meticulous Japanese ink drawing. Invent a unique mecha, not an existing
character or unit. A towering slender biomechanical machine is shown in a dramatic
close three-quarter profile, head, neck and shoulder armor cropped boldly;
elongated armored face, complex exposed neck tendons and precision-machined
articulation, long restrained angular armor planes, one tiny coral optical sensor.
A beautifully articulated hand appears in the lower foreground, very delicately
aligning a single taut horizontal coral filament between two precision guide
fingers: the unmistakable visual motif is a boundary/line being kept under tension.
Make the anatomy and hand mechanically coherent. The machine is a calm, enigmatic
instrument, not fighting. Highly refined traditionally hand-drawn manga ink and
graphite, exquisite thin contours, confident bold black shapes, selective
crosshatching and screentone, tactile paper-like mark quality, dramatic deep
shadows and bone-white highlights. Cinematic editorial artwork, intelligent
negative space, NO plastic 3D rendering or generic anime glossy shine. Palette
strictly deep midnight navy #0d1024, warm off-white ink, muted gray; sparse vermilion
coral #d65c46 accents only on sensor, tiny armor detail and the filament. No purple
or lime-green armor. Background is flat midnight navy seamlessly extending to all
four edges, with a few very restrained drafting marks near the mechanism only.
Strong portrait 4:5 composition with the mecha central-right, facing slightly left
toward web headline outside frame. Visual density concentrated in head and hand,
enough breathing space around silhouette. No text, no typography, no logos, no
watermark, no weapons, no explosions, no cityscape, no UI, no neon glow, no gradients.
Highest polish: purposeful line weights, intricate yet readable forms, stunning
illustration that feels like a special-edition manga frontispiece.
